SPOTIFY-INSPIRED MUSIC PLAYER
==============================

1. ZIP extract karein.
2. spotify_clone folder open karein.
3. index.html par double-click karein, ya VS Code mein Live Server se open karein.
4. Play button dabayein. Internet connection zaroori hai kyun ke demo audio aur cover images online load hoti hain.

Features:
- Responsive Spotify-inspired dark interface
- Working audio player with play/pause, next, previous
- Progress bar / seek
- Volume control
- Shuffle and repeat
- Search tracks
- Like button (visual only)
- Add playlist name (visual only)

Important:
This is an original Spotify-inspired practice project, not an exact copy of Spotify.
The included SoundHelix MP3s are demo audio tracks. Replace each song's `src` in script.js
with audio files you own or have permission to use. To use local MP3s, put them in an
`audio` folder and use paths such as `audio/my-song.mp3`.
